# CS2 对手经济推算

读 CS2 官方 **Game State Integration（GSI）** 的推送数据，推算对手这一回合有多少钱、能买什么，
用本地网页 + 语音显示出来。

> 只监听 `127.0.0.1`，只读游戏主动推送的数据。不注入进程、不改游戏文件、不模拟任何输入、
> 不做任何自动化操作。和 Stream Deck 的 CS2 插件、OBS 直播覆盖层用的是同一套官方接口。

---

## 一、经济计算原理

### 1. 先划清楚能算哪一侧

钱花在哪，GSI 一个字都不说。所以**支出侧推不出来，只算收入侧**，再把上界当结论用。

### 2. 收入侧：逐回合重建胜负序列

1. 给每个回合存一份比分快照 `roundScore[round] = {ct, t}`。
2. 相邻两个快照相减 → 重建对手每一回合的胜负序列（`buildSequence`）。
3. 按 CS 的确定性规则累加：起始资金 + 每回合基础资金 + 胜负奖金 + 连败补偿阶梯
   `1400 / 1900 / 2400 / 2900 / 3400`。
4. 两笔容易漏的一次性奖金也要算上（见下表）。

> **换边的坑**：GSI 在 `intermission` 那一帧给的是**换边前**的比分，下一帧左右互换。
> 所以快照必须**整对存**、并以「你自己的阵营」为参照系翻回来。
> 逐字段取最大值会拼出一个从未出现过的比分，后半场整条连败阶梯从此错位。

**两笔容易漏的一次性奖金**

| 情况 | 每人 | 依据 |
| --- | --- | --- |
| 回合**以炸弹结束**（引爆 / 拆除）而获胜 | **`$3500`**，不是 `$3250` | 实测：`round.bomb = exploded` 那一回合结算 `+$3500`，其余三回合都是 `+$3250` |
| **T 埋了包却输掉** | 额外 **`+$800`** | 实测有个 `+$2700` 的结算 = `1900`（二连败）`+ 800` |

累积器在 `acc.roundPlant[回合]` 记「这回合埋过包没有」（见到 `round.bomb = 'planted'` 就记，
换局清空）。两笔都只往**收入**上加，方向上永远安全 —— 上界偏松，不会给出假的「对面没钱」。

### 3. 最后给三个数字

| 字段 | 含义 |
| --- | --- |
| 人均累计收入 | 硬算的**下界**：对手至少有过这么多钱，不含击杀奖励 |
| 人均资金上界 `cashCeil` | 假设**一分钱都没花** + 击杀收入上界，按模式封顶 |
| 参考余额 `cashLikely` | 上界扣掉**估算支出**。只在测到对手死亡数时才有，仅供参考 |

**下结论用的是上界。** 逻辑很直接：连「一分钱没花」都凑不出长枪的钱，
那对手这回合就一定不可能人人长枪 —— 这是确定性结论，不依赖任何猜测。

### 4. 击杀收入

对手一回合最多拿 5 个人头（我们最多死 5 人），这 5 份奖励**全队平分**，
所以「**人均每回合 ≤ 每杀平均奖励**」这条上界不用假设他们杀几个人就成立。

「每杀平均奖励」不是一个固定值，要按回合分开算：

| 场合 | 竞技 | 休闲 | 为什么 |
| --- | --- | --- | --- |
| 普通回合 | `$279` | `$140` | 按实测武器占比加权：步枪/手枪 `$300`、微冲 `$600`，但 **AWP 只有 `$100`**，会把均值拖下来 |
| **手枪局** | `$300` | `$150` | 起始资金连 `$1050` 的微冲都买不起，只可能用手枪 —— **没有 AWP 来拖**，所以均值更高 |

所以序列里混着手枪局时不能简单乘回合数，要**逐回合取奖励**（`killIncomeOf`）。

能实测时就用实测：**记下被旁观者的累计总击杀（`player.match_stats.kills`），
跟上一回合的相减**，就是他那一回合的真实击杀数。他这几回合一个人头都没拿时，
实测直接给 `0` —— 假设值永远给不出 `0`。

有数据 → `killSource = measured`；没有 → `assumed`，且 `killsPerRound` 是 `null`
而不是编一个数。换图 / 换局时账本清空 —— 击杀数是按局累计的，留着会拼出假差值。

### 5. 参考余额怎么估

和算击杀是同一个套路，只是减的对象反过来：**记下被旁观者的累计死亡
（`player.match_stats.deaths`），跟上一回合相减**，就是他那一回合死了几次。
死一次身上的枪就没了、下一回合得重买，所以

```
估算支出 ≈ 人均每回合死亡数 × 重购成本 × 回合数
cashLikely = cashCeil − 估算支出
```

> ⚠️ 它**不进上界，也不驱动档位**，这是刻意的。
> 这个项目早先试过「理性消费模拟」去推余额，结论是**余额低 ≠ 没装备**：
> 对手刚满买完余额当然是 0，可人家身上是全套枪 —— 用余额判档会得出
> 「对面在存钱」这种正好相反的结论。所以 `cashLikely` 只出现在说明里当参考，
> 下结论永远只认 `cashCeil`。

### 6. 经济常数按模式分两套

**休闲不是「竞技少几个人」，规则本身就不一样**：

| 项目 | 竞技 / 优先 | 休闲 |
| --- | --- | --- |
| 起始资金 | `$800` | `$1000` |
| 回合胜利 | `$3250` | `$2700` |
| 资金上限 | `$16000` | `$10000` |
| 击杀奖励 | ×1（普通回合 `$279` / 手枪局 `$300`） | **×0.5**（`$140` / `$150`） |
| 每回合护甲 | 要买（`$1000`） | **免费送** |

所以「长枪门槛」也跟着模式走：竞技 `$3700`（步枪 + 甲盔），休闲 `$2700`（只要步枪）——
**同一个局面，两个模式能下的结论完全相反。**

两套常数都用真实日志逐回合对账过：休闲侧 `$3150 = 2700 + 3×150` 这类算式分毫不差；
竞技侧只看「前后两帧都是你本人」的相邻帧，取 `previously.player.state.money` 的差值，
拿到干净事件（`+3250 ×12`、`+3500 ×1`（炸弹引爆）、`+300`、`+600`、连败阶梯 4 档）。
`lib/enemy.js` 里的 `MODES` 就是这两张表，`map.mode` 一来就自动选。

## 二、配置方法

### 1. 环境

Node.js 即可。**零第三方依赖，不需要 `npm install`。**

### 2. 启动

Windows 上双击项目里的 `start.bat`。它会：

1. 自检旁边有没有 `server.js` —— 没有就明确报错，不会傻开着浏览器
2. 找 node（PATH → WorkBuddy 自带版本 → 兜底扫描，跳过 Microsoft Store 的假 node）
3. 检查 31982 端口，服务已在跑就只打开页面、不重复启动
4. 服务**真正监听成功之后**才打开浏览器

也可以在本目录下直接跑：

```
node server.js
```

看到 `CS2 Buy Helper 已启动（对手经济推算）` 就对了。**这个窗口打游戏时要一直开着。**

> **不要把 `start.bat` 单独复制到桌面。** 它必须和 `server.js` / `lib` / `public`
> 待在同一个文件夹。单独复制的结果是：node 找不到 `server.js` 立刻退出，
> 浏览器却照样打开显示「拒绝连接」。想要桌面入口就发个快捷方式。

### 3. 安装 GSI 配置

```
node tools/install.js
```

脚本会自动从 Steam 注册表和各个库目录里找到 CS2，把
`gamestate_integration_buyhelper.cfg` 写进 `game\csgo\cfg\`，并回读校验端口。
看到 `[ OK ] 配置已写入` 就成功了。

```
node tools/install.js "D:\SteamLibrary"      # CS2 装在非常规盘位时，指定库根目录
node tools/install.js --check                # 只查找，不写文件
node tools/install.js --port 32000           # 换端口写配置
node tools/install.js --no-reg               # 跳过注册表探测
```

手动安装就是把 `gamestate_integration_buyhelper.cfg` 复制到：

```
C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\
```

**5E 启动的也是 Steam 版 CS2，配置放同一个位置即可。** 库不在 C 盘的，
换成对应盘符下的 `steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\`。

找不到路径时：Steam 库 → 右键 CS2 → **管理** → **浏览本地文件** → 进 `game\csgo\cfg\`。

### 4. 重启 CS2

GSI 配置**只在游戏启动时读取**，必须完全退出游戏再进。

### 5. 打开页面

```
http://127.0.0.1:31982/
```

| 地址 | 用途 |
| --- | --- |
| `/` | 覆盖层主界面：我的状态 + 敌方推演 |
| `/debug.html` | 抓包 / 校准页：实际拿到哪些字段、增量帧有没有被合并、重建出的胜负序列 |
| `/preview.html` | 离线预览，样例是引擎真实输出，不开游戏也能看效果、试听语音 |

### 6. 自检

```
node tools/selftest.js
```

期望 `0 BAD`。日志被清掉时，「真实日志回放」那几组会自动跳过，不影响其他校验。
